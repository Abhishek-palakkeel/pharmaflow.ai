# PharmaFlow AI — API Documentation

Base URL (local dev): `http://localhost:8000`

Interactive Swagger UI is auto-generated by FastAPI and available at:
**`http://localhost:8000/docs`** (and ReDoc at `/redoc`)

All endpoints except `/api/auth/login` and `/` require a `Authorization: Bearer <token>` header.

---

## Authentication

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/login` | Log in with email/password, returns a JWT |
| GET | `/api/auth/me` | Get the current authenticated user's profile |

## Employees (Admin only for write ops)

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/employees` | List employees (filter: `search`, `territory`) |
| GET | `/api/employees/{id}` | Get one employee |
| POST | `/api/employees` | Create employee (creates linked user login) |
| PUT | `/api/employees/{id}` | Update employee |
| DELETE | `/api/employees/{id}` | Deactivate employee |

## Customers

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/customers` | List customers (filter: `search`, `type`, `territory`, `assigned_employee_id`) |
| GET | `/api/customers/{id}` | Get one customer |
| POST | `/api/customers` | Create customer (admin) |
| PUT | `/api/customers/{id}` | Update customer (admin) |
| DELETE | `/api/customers/{id}` | Deactivate customer (admin) |

## Work Plans

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/work-plans` | List work plans (filter: `employee_id`) |
| POST | `/api/work-plans` | Create a work plan with a list of `customer_ids` |
| PUT | `/api/work-plans/{id}/complete` | Mark a plan complete |
| DELETE | `/api/work-plans/{id}` | Delete a plan |

## Visits

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/visits` | List visits (filter: `employee_id`, `status`, `date_from`, `date_to`) |
| POST | `/api/visits` | Schedule a new visit |
| PUT | `/api/visits/{id}` | Update a visit |
| POST | `/api/visits/{id}/check-in` | Check in (timestamps `check_in_time`) |
| POST | `/api/visits/{id}/check-out` | Check out with notes + outcome; triggers NLP analysis |
| DELETE | `/api/visits/{id}` | Delete a visit |

## Follow-Ups

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/follow-ups` | List follow-ups (filter: `employee_id`, `bucket`, `status`) — `bucket` is one of `overdue`, `today`, `upcoming` |
| POST | `/api/follow-ups` | Create a follow-up |
| PUT | `/api/follow-ups/{id}` | Update a follow-up (e.g. mark completed) |
| DELETE | `/api/follow-ups/{id}` | Delete a follow-up |

## Dashboard

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/dashboard/summary` | Real aggregate metrics (employees, customers, visits, follow-ups, monthly trend, distribution) |
| GET | `/api/dashboard/insights` | Plain-English performance insights comparing periods |

## AI Insights

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/ai/priority` | Rule-based 0–100 priority score for all customers (optionally filtered by `employee_id`) |
| GET | `/api/ai/priority/{customer_id}` | Priority score + explanation for one customer |
| GET | `/api/ai/ml-predict/{customer_id}` | ML (RandomForest) predicted priority + confidence + top factors |
| GET | `/api/ai/model-info` | Current model algorithm, features, and feature importances |
| POST | `/api/ai/model-retrain` | Force retrain the ML model on synthetic data |
| GET | `/api/ai/recommendations/{employee_id}` | Top-N recommended customers to visit next, with explanations |
| POST | `/api/ai/analyze-note` | Local NLP sentiment/keyword/follow-up analysis of arbitrary text (`{"text": "..."}`) |

---

## Example: Login

```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@pharmaflow.ai", "password": "Admin@123"}'
```

## Example: ML priority prediction

```bash
curl http://localhost:8000/api/ai/ml-predict/1 \
  -H "Authorization: Bearer <token>"
```
